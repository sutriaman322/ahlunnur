# Ahlunnur — halaman unduh

Halaman statis untuk mengunduh aplikasi Android **Ahlunnur** secara gratis.
Tidak untuk diperjualbelikan.

## Isi

| Berkas | Keterangan |
|---|---|
| `index.html` | Halaman unduh |
| `style.css` | Gaya, mobile-first, ikut mode gelap |
| `ahlunnur.apk` | Berkas aplikasi, versi 1.0 |

## Aplikasi

- Al-Qur'an 114 surah / 6.236 ayat (Tanzil Utsmani + terjemahan Kemenag)
- Al-Ma'tsurat Qubra susunan Imam Hasan al-Banna — 44 bacaan
- Kajian Ushul Isyrin — 20 materi
- Jadwal salat dan arah kiblat
- Seluruh isi di dalam APK, berjalan tanpa internet

Android 7.0 ke atas · paket `com.ahlunnur.app`
